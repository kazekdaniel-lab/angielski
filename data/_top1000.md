# Moduł "1000 słów" - schemat fiszek

Uczeń: Polak, poziom A1-A2, zainteresowania: biznes, e-commerce, marketing. Moduł uczy 1000 najczęstszych słów angielskiego metodą fiszek z pudełkami (system Leitnera). Kolejność i lista słów: NGSL (New General Service List), plik `tools/ngsl-1000.tsv` (numer, słowo, formy pokrewne z listy). Lista jest STAŁA: nie zmieniaj, nie dodawaj, nie usuwaj, nie zmieniaj kolejności.

## Pliki

10 plików po 100 słów: `data/top-01.js` (słowa 1-100), `data/top-02.js` (101-200), ... `data/top-10.js` (901-1000).

```js
window.TOP = window.TOP || [];
window.TOP.push(
  { n: 1, en: "the", ... },
  { n: 2, en: "be", ... }
);
```

Poprawny JavaScript, stringi w podwójnych cudzysłowach. Wewnątrz tekstu nie używaj znaku `"` (jeśli musisz coś wyróżnić, pisz WIELKIMI LITERAMI). Bez komentarzy poza pierwszą linią pliku.

## Struktura fiszki

```js
{
  n: 31,                                  // numer z listy NGSL
  en: "go",                               // słowo z listy (jedyny wyjątek: "i" piszemy "I")
  pl: "iść, jechać",                      // główne znaczenie, 1-3 polskie odpowiedniki po przecinku; dwa różne znaczenia oddziel "; " (np. "dobrze; no cóż"); krótko, do ok. 40 znaków
  say: "gou",                             // wymowa polskimi literami, amerykański angielski (konwencja niżej)
  pos: "czasownik",                       // część mowy z listy niżej; jeśli słowo jest często użyte jako dwie: "czasownik, rzeczownik" (ważniejsza pierwsza, max 2)
  forms: "went, gone (nieregularny)",     // tylko to, co nieregularne albo ważne: formy czasownika nieregularnego, nieregularna liczba mnoga ("l.mn. children"), stopniowanie nieregularne ("better, best"), formy zaimka ("me, my, mine"); inaczej ""
  ex: [                                   // DOKŁADNIE 2 zdania, 3-10 słów, gramatyka A1-B1
    { en: "I go to work by bus.", pl: "Jeżdżę do pracy autobusem." },
    { en: "We went to Berlin last week.", pl: "W zeszłym tygodniu pojechaliśmy do Berlina." }
  ],
  phrases: [                              // 2-3 najczęstsze połączenia lub zwroty z tym słowem
    { en: "go home", pl: "iść do domu" },
    { en: "go shopping", pl: "iść na zakupy" },
    { en: "Let's go!", pl: "Chodźmy!" }
  ],
  note: "Go to i iść, i jechać. Mówimy go home, bez to."   // pułapka dla Polaka, 1-2 zdania; "" jeśli nie ma nic ważnego
}
```

Przykład słowa funkcyjnego:

```js
{ n: 1, en: "the", pl: "ten, ta, to (zwykle bez tłumaczenia)", say: "de", pos: "rodzajnik", forms: "",
  ex: [ { en: "The shop is open.", pl: "Sklep jest otwarty." }, { en: "Can you send me the invoice?", pl: "Możesz mi wysłać tę fakturę?" } ],
  phrases: [ { en: "the same", pl: "ten sam" }, { en: "the best", pl: "najlepszy" } ],
  note: "The stawiamy, gdy wiadomo, o którą rzecz chodzi. Przed samogłoską czytamy di: the apple [di epl]." }
```

## Części mowy (pole `pos`)

rzeczownik, czasownik, czasownik modalny, przymiotnik, przysłówek, liczebnik, przyimek, zaimek, spójnik, rodzajnik, partykuła, wykrzyknik, wyrażenie

## Zasady treści

- Przykłady: pierwszy z codziennego życia, drugi z pracy, biznesu, sklepu internetowego albo marketingu, jeśli to brzmi naturalnie (nie na siłę). Jeśli słowo ma dwa ważne znaczenia, każdy przykład pokazuje inne.
- Każde zdanie w `ex` MUSI zawierać to słowo albo jego formę (is, went, children, her...). Walidator to sprawdza.
- Zdania krótkie i naturalne, takie, jakie mówi się naprawdę. Polski naturalny, jak mówi człowiek, zero kalek z angielskiego.
- `note` pisz, gdy jest realna pułapka: fałszywy przyjaciel (actually = właściwie, nie aktualnie), kilka znaczeń, nieregularność, typowy błąd Polaka, zaskakująca wymowa, różnica z podobnym słowem. Zwykle 1 zdanie, max 2. Bez lania wody.
- Liczby w polskich tekstach cyframi.
- Myślnik: wyłącznie zwykły "-" (U+002D). NIGDY półpauza (U+2013) ani pauza (U+2014).
- Imiona w przykładach: zwykłe angielskie (Anna, Tom, Kate, Mark). Nie zmyślaj faktów o prawdziwych firmach ani osobach.

## Wymowa polskimi literami (pole `say`), amerykański angielski

- w -> ł (water [łoter], week [łik]); th bezdźwięczne -> f (thought [fot], think [fynk]); th dźwięczne -> d (the [de], mother [mader])
- sh -> sz, ch -> cz, j / g miękkie -> dż (job [dżob], page [pejdż])
- długie i -> i (meet [mit]); krótkie i -> y (sit [syt]); ei -> ej (day [dej]); ou -> ou (go [gou]); ai -> aj (time [tajm]); au -> ał (hour [ałer], now [nał])
- a jak w cat -> e (cat [ket]); u jak w cup -> a (cup [kap], Monday [mandej]); nieakcentowane neutralne "e" -> e (about [ebałt], a [e])
- er na końcu -> er (manager [menedżer]); r wymawiane
- Bez znaków akcentu, bez apostrofów, małe litery, bez nawiasów (nawiasy dodaje aplikacja). Kilka sylab piszemy razem (ebałt), bez spacji, chyba że to dwa słowa.
